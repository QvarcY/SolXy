SolXy

Kas ir SolXy?

Eksperiments par to, cik tālu var aiziet ar semantisku HTML un modernu CSS bez JavaScript.

SolXy ir statiska Saules sistēmas izpētes vietne ar animētu sākumlapu un pakāpeniski publicētu saturu par planētām, pavadoņiem un astronomijas datiem.

Sākotnējā publiskā versija veido projekta čaulu: navigāciju, dizaina sistēmu, animēto Saules sistēmas skatu, dokumentāciju un sagatavotus maršrutus nākamajām sadaļām.

Tehnoloģijas

Bez JavaScript runtime

HTML5, CSS Grid, Flexbox, Custom Properties, gradients, transitions un keyframe animācijas.

HTML5

Semantisks marķējums, piekļūstamības atribūti un daudzlapu struktūra.

Tīrs CSS

Planētas, orbītas, zvaigznes un interaktīvie stāvokļi bez JavaScript.

Pakāpeniska attīstība

Satura sadaļas tiek pievienotas pa vienam loģiskam projekta komponentam.
